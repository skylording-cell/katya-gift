# Сайт для Кати ❤️

Готово для GitHub Pages.

## Файлы
- `index.html` — страница
- `style.css` — дизайн и адаптивность
- `script.js` — анимации и музыка
- `assets/` — фотографии и музыка

## Что нужно добавить
Положи в `assets/`:
- `katya-hero.jpg`
- `katya-2.jpg`
- `katya-3.jpg`
- `katya-4.jpg`
- `hero-bg.jpg`
- `sunset-bg.jpg`
- `final-bg.jpg`
- `music.mp3`

Имена можно оставить такими же — тогда ничего в коде менять не нужно.

> В комплект не включён аудиофайл `smokedope2016 - In Da Party`. Добавь свой легально полученный MP3 в `assets/music.mp3`.

## GitHub Pages
1. Загрузи все файлы в репозиторий `katya-gift`.
2. Открой **Settings → Pages**.
3. Source: **Deploy from a branch**.
4. Branch: **main**, folder: **/(root)**.
5. Нажми **Save**.
6. Через некоторое время сайт будет доступен по адресу:
   `https://skylording-cell.github.io/katya-gift/`
